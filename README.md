# MarkdownPreviewStyle

En este proyecto encontrarás el archivo CSS utilizado para [personalizar los estilos de la vista previa de Markdown en VSCode](https://www.codearco.net/tutoriales/herramientas-software/cambiar-estilo-vista-previa-markdown-vscode/). A través del enlace podrás acceder a una guía completa con el paso a paso para realizar dicha modificación en tu editor de código.

In this project you'll find the CSS file used to [customize Markdown preview styles in VSCode](https://www.codearco.net/en/tutorials/tools-software/change-preview-style-markdown-vscode/). The link takes you to a complete step-by-step guide on how to make this change in your code editor.
